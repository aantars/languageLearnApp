# LanguageLearnApp

A single-page app where Spanish speakers learn and practice basic German. It is organised into Sections, each with a Learn view and a Practice view.

## Language

**Section**:
A self-contained topic of the app that the user picks from the home screen: Numbers (0–20) or Alphabet (A–Z plus Ä, Ö, Ü, ß).
_Avoid_: Module, course, category, tab

**Range**:
A subset of the items of a Section (e.g. 7–12 in Numbers) that restricts what is shown in Learn and drawn in Practice.
_Avoid_: Scope, level, filter

**Mode**:
A type of exercise inside Practice (e.g. Listen, Type the word, Dictation).
_Avoid_: Game, quiz type, exercise type

**Item**:
A single thing to be learned within a Section: one number or one letter.
_Avoid_: Entry, card (a card is only how an Item is displayed in Learn)

**Dictation**:
A Mode where the voice reads several Items aloud and the user types what they heard.
_Avoid_: Listening test

**Spelling dictation**:
A Dictation in the Alphabet Section where the voice spells a word letter by letter and the user types the word.
_Avoid_: Spell mode
